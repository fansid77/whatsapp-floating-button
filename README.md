# 💬 Free WhatsApp Floating Button Generator

Alat sederhana berbasis web (*HTML/JavaScript*) untuk membuat tombol chat WhatsApp melayang (*floating widget*) yang bisa dipasang di website apa saja secara gratis. Proyek ini dikembangkan oleh [profesor.web.id](https://profesor.web.id).

---

## ✨ Fitur Utama
* **Ringan & Tanpa Plugin Tambahan:** Murni menggunakan HTML & CSS standar, tidak memberatkan performa website.
* **Kustomisasi Pesan:** Pengguna bisa mengatur nomor tujuan dan teks pesan default secara instan.
* **Responsive:** Nyaman dilihat di komputer maupun *smartphone*.

---

## 🚀 Cara Menggunakan
1. Buka halaman demo live tool ini disini: **[WhatsApp Floating Button](https://fansid77.github.io/whatsapp-floating-button)**
2. Masukkan nomor WhatsApp dan pesan otomatis yang diinginkan.
3. Klik tombol **Generate**, lalu salin (*copy*) kode HTML yang dihasilkan.
4. Tempelkan kode tersebut tepat di atas tag penutup `</body>` pada website Anda.
